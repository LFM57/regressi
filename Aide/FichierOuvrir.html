Fichier|Ouvrir

Général ››

On peut ouvrir un fichier de type

  • *.RRR (Regressi DOS)
  • *.RW3 (Regressi Windows 3.1)
  • *.LAB (généré par VTT et Généris) (récupération des données expérimentales)
  • *.CSV (fichier texte avec comme séparateur la virgule)
  • *.TXT tableur ASCII obéissant au même format que le presse-papiers. En particulier, on peut échanger des fichiers avec Excel par l'intermédiaire de ce format. Sous Regressi ou Excel sélectionner Fichier|Enregistrer sous et sélectionner comme type “Tableur texte avec tabulations” pour sauvegarder. Pour lire sélectionner Fichier|Ouvrir et sélectionner ce même type (extension *.txt en général).

On récupère ainsi les données fourni par les oscilloscopes Velleman. et ceux fourni par les stations météo.

Le répertoire de travail est géré dans le menu principal options onglet fichiers, répertoires.

Remarque : on peut également indiquer un répertoire partagé. Cela permettra d'utiliser la commande Fichier/Envoyer qui envoie les données courantes dans un fichier tampon qui pourra être récupéré par un autre poste grâce à la commande Fichier/Recevoir.
